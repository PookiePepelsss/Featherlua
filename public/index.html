Intro

Everything happens inside the tab. The Luau compiler is a WebAssembly build of the official one, pinned to a known revision and checked against a hash before use. Nothing is uploaded, logged or kept.

Three modes, from a whitespace pass that only checks tokens to a full AST rewrite that renames every local. Every pass in Aggressive has its own checkbox.

Every input and output goes through the compiler before you see a result. Aggressive re-parses its own output and checks it matches what it meant to produce. If something is ambiguous, it is reported rather than guessed at.

Modes

Pick how far the rewrite goes.

Each mode is a stricter promise about what stays the same. Start safe, move down the list when you know what your script can tolerate.

Verification

Smaller means nothing if it prints something else.

Most of the ~1,200 checks are not unit tests. Scripts are compiled and run by the official Luau build before and after compression and have to print the same thing. Generated programs go through every combination of passes, and the grammar this parser accepts is compared against the one Luau accepts.

Type run tests into the box to check the build in front of you: a dozen scripts, all three modes, every output has to compile, run and print what the original printed.
Pinned compiler. The Luau WASM asset is fixed to playground revision 736e1d9 and checked against a known hash before use.
Honest about limits. Scripts past roughly a megabyte stop fitting the compiler's memory. They are refused with an explanation, not a crash, and the compiler is rebuilt for the next one.
